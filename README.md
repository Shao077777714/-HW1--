# 銀杏日和｜日本銀杏見頃動態地圖

繁體中文純前端網站。直接雙擊 `index.html` 即可使用；OpenStreetMap 底圖需要網路。也可在本資料夾執行 `python -m http.server 8080 --bind 127.0.0.1`，開啟 http://127.0.0.1:8080/ 。無框架、後端、API 金鑰或資料庫。

## 使用

手機版打開後先顯示地圖，向下捲動可查看圖例、日期控制、搜尋篩選與其他內容；桌機維持原本的左右欄配置。

1. 選日期或拖動10–12月滑桿；播放支援1×、2×、4×。
2. 搜尋中／日文名稱或城市，篩選地區、葉況、推薦度，或勾選「只看見頃」。
3. 點景點結果、Marker、推薦或時間軸，查看完整資訊。手機會直接捲至地圖；Popup 可內部捲動。
4. 切換「歷年平均／例年參考」與「2026城市預報參考」。所有景點葉況均明示本站推估。
5. 選半日／一日路線；虛線只表示景點順序，實際步行路線另開Google Maps。
6. 在資料來源展開41筆紀錄，查看列號、group_id、景點對應與限制；可下載三份JSON。
7. 第一次進入會詢問是否需要操作導覽。可開始六步導覽，或選「先自行探索」；選擇會記住於同一瀏覽器。之後可按頁首「操作導覽」重新查看，支援上一步、下一步、跳過與 Escape 關閉。

## 葉況與模型的界線

快照查核日為2026-10-08，本次未取得2026景點銀杏實測，`current_observation`／`observation_date` 均為null。八王子官方2026-09-22照片的日期已確認，但未從照片自動推斷葉況。老師表的 `audited_at`、文章 `evidence_date`、祭典日期不充當葉況日期。

JMA城市平年值以2025日期及原頁平年差核對：東京11/23–12/3、札幌11/4–11/11、名古屋11/18–12/3、京都11/24–12/4、大阪11/22–12/4、熊本11/27–12/8、鹿兒島11/25–12/6。這是城市標本木參考，不能宣稱為每處景點最佳觀賞期。來源：[黃葉日](https://www.data.jma.go.jp/sakura/data/phn_012.html)、[落葉日](https://www.data.jma.go.jp/sakura/data/phn_013.html)。

2026預報僅使用10月1日公布的城市銀杏黃葉日期：札幌11/3、東京11/26、名古屋11/17、京都11/27、大阪11/24、鹿兒島11/27；熊本未取得本次表中城市預報，保留歷年參考。[日本氣象株式會社](https://n-kishou.com/corp/news-contents/autumn/) 是民間氣象公司，並非日本氣象廳。

模型規則：

- 官網明載例年見頃範圍者採該範圍；上／中／下旬用1–10、11–20、21–月底作日曆示意。
- 只有廣泛黃葉季的昭和公園（10月下旬–11月下旬）與八王子（11月前後），另保留 `official_yellow_season`。本站以季節中段14天示意見頃：昭和11/8–11/21、八王子11/9–11/22；這些是模型設定，並非官方發布日期。
- 其他景點以城市JMA平年黃葉日至平年落葉日參考，並於參考期前14日展示轉黃、結束後7日展示落葉。銀杏本身主要由綠轉黃；橘色只代表介面的落葉階段。
- 城市預報模式，以2026城市預報黃葉日相對城市平年日的差，平移該城市景點參考時間帶。本站推估不等於景點官方預報。
- 推薦星等是編輯評分；推薦排序依示意葉況、星等與參考時期距離。
- 路線只串接起點4.5公里內的收錄點，最多半日2站、一日4站，避免把跨城市景點假裝成步行行程。步行估算＝球面直線距離×1.4／4.5公里時速；停留60／90分鐘，一日另含60分鐘休息。若附近僅一站，明示單點慢遊。
- 溫度為所選月份的「平年日最低／最高平均」，不是當日溫度或未來天氣預報。東京近郊使用東京站、垂水使用鹿兒島站，無微氣候校正。

## 更新與交付檔案

編輯景點請更新 `scripts/build-spots.py`，執行後重建JSON與site-data.js；氣候更新可執行 `scripts/prepare-data.py`，再執行 `scripts/build-spots.py`。Windows抓取使用PowerShell WebRequest以配合系統網路設定。老師表更新應重新透過唯讀connector取得快照；不以現有頁碼推定文章永久位置。

網站是可操作的資料快照，沒有自動爬取、背景排程或即時導航。老師提供的「建議輪詢頻率」只是來源說明，本次沒有建立排程。出發前請點原始來源查最新公告。

`assets/ginkgo-branch.png` 是本次內建ImageGen生成的裝飾插畫，非現地照片。提示重點：透明背景、細枝、放射葉脈、金黃色及深綠扇形銀杏葉、和紙水彩質感、無文字。三張介面概念作設計參考，不嵌入網站UI。

Leaflet 1.9.4及Leaflet.markercluster 1.5.3已保存於 `vendor/`，授權文字一併交付；OSM標示保留於地圖。HTML、CSS、JS及所有本機引用資源隨資料夾交付，整個資料夾搬移後仍可開啟。
